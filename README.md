# Vibgyor Advisors E-Commerce System

## 🏢 About the Company
Vibgyor Advisors is a first-generation firm focusing on financial services. It works across various segments of financial services and provides a wide range of services to its esteemed clients. This project is developed as part of the VIBGYOR Integrated Internship program.

## 🛒 Project Overview
The primary objective of this project is to create an e-commerce platform that offers a seamless shopping experience for users, while ensuring security, performance, and scalability. The platform will feature core functionalities such as user authentication, product catalog, shopping cart, payment integration, and order management.

## 🏗️ Technology Stack
- **Frontend Framework:** ReactJS (Designed for responsive layout, clear dashboard, and top navigation bar)
- **Backend Framework:** Java Spring Boot
- **Database:** Relational Database (SQL) 

## 🗄️ Database Design
A well-structured relational database designed with the following key tables:
- **User:** Stores User information
- **Product:** Stores product related information
- **Cart:** Stores cart related information (products added in cart)
- **Orders:** Stores information related to orders placed by the user
- **Payment:** Stored information related to Payment done by user for an order.

Proper Entity Relationships (e.g., One-to-Many between users and orders) will be established.

## 🚀 Features implemented
### Category Management (First Module)
- **Create a New Category:** Admins can create new categories.
- **Category Dashboard:** Displays all categories with options to edit/delete, along with the product count.
- **Update Category:** Modify the name or description of categories.
- **Delete/Deactivate Category:** Soft delete implemented using the status column in the database with a prior warning message.
